# New kiss_ai Research Project

This project was created from the `kiss_ai` template.

## Getting Started

Continue in the `kiss_ai` web app. The browser interface is the normal way to define, build, review, and evolve this project.

1. Open this project in the web app.
2. Edit **project.md** to describe your goal, context, topics, and desired outputs.
3. Add any documents to **inputs_human/** (optional).
4. **Build the project** to generate research outputs.
5. Review outputs and add annotations using the [+] button.

## Project Files

**You write and edit:**

- `project.md` — your project brief: goal, topics, outputs, constraints
- `human_design_identity.md` — visual identity and design preferences
- `inputs_human/` — your documents, notes, PDFs, data files

**The AI creates and updates:**

- `sources/` — gathered evidence and source tracking
- `outputs_ai/` — wiki pages, reports, and other deliverables
- `questions.md` — open questions needing your input
- `.build/manifest.json` — build record
- `change_logs/` — build history

## How Annotations Work

When reviewing AI-generated outputs, use the [+] button to add feedback. Your feedback appears as a blue annotation. On the next build, the AI reads your feedback, applies it, and removes the marker.

The AI may also leave green suggestions for improvements. You can accept, dismiss, or modify them.

## Shared Framework

The shared framework lives at `../_kiss_ai/framework/`. Do not create a project-local `framework/` folder.
