# Step Outputs Prompt

Target file: `human_output_requirements.md`

Purpose: ensure output requirements fully address the controlling goal.

Use the accepted or current `human_goal_requirements.md` as the source of truth. Review the current output requirements, input requirements, open questions, Git edit signals, AI-managed annotations, and available source signals.

The output file should clearly capture:

- wiki organization, topic hints, concept rules, and article expectations
- directed outputs, reports, summaries, deliverables, and review artifacts
- required sections, citation expectations, confidence/caveat handling, and quality criteria
- structural requirements for outputs that must serve the goal
- how outputs should expose unresolved questions, source gaps, risks, or decision-relevant uncertainty

If the output requirements conflict with the goal, align them to the goal. If the goal implies missing wiki/article/report requirements, add them. If current output directives are stale, duplicative, too broad, or misaligned, rewrite them carefully and explain the change.

Do not expand deliverables beyond what the goal requires. Prefer clear durable output policy over over-specific one-off formatting unless the requirement is important to the user.
